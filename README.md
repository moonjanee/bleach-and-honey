# BLEACH & HONEY — ART & TATTOO FLASH PORTFOLIO

Visual art and tattoo flash portfolio for **Bleachjane**, visual artist and prospective tattoo apprentice based in South Africa.

Built using HTML5, CSS3 (Custom Variables, CSS Grid/Flexbox), and vanilla JavaScript. Features custom dark/light theme switching, custom cursor hot-spot integration, interactive artwork filtering, and modal overlays.
